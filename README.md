# 🏋️ AI Gym & Fitness Assistant

An AI-powered fitness application that helps users improve their health through intelligent workout guidance, personalized diet recommendations, fitness tracking, and AI-based assistance. The application combines computer vision and artificial intelligence to provide an interactive fitness experience for users of all fitness levels.

## 🌐 Live Demo

**Streamlit App:**  
https://ai-gym-fitness-assistant-qirkxkfmfcktsyowxmmmlf.streamlit.app/

---

## ✨ Features

### 🏋️ AI Gym Trainer
- Real-time squat posture detection
- Automatic squat repetition counting
- Exercise form analysis using MediaPipe
- Live webcam-based workout assistance

### 🥗 AI Diet & Nutrition Assistant
- BMI calculation
- Daily calorie estimation
- Personalized diet recommendations
- Nutrition guidance based on fitness goals

### 📊 Fitness Habit Tracker
- Track daily workouts
- Monitor fitness consistency
- Visualize workout progress

### 🤖 Virtual Gym Buddy
- AI chatbot for fitness-related queries
- Workout guidance
- Nutrition advice
- Motivation and recovery tips

### 📈 Performance Analyzer
- Analyze workout performance
- Calculate performance scores
- Display fitness insights

### 💓 Smart Gym Assistant
- Simulated smart fitness monitoring
- Heart-rate based recommendations
- Personalized workout suggestions

### 📍 Gym Recommender
- Suggests suitable gyms based on user preferences

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/AI-Gym-Fitness-Assistant.git
```

### Navigate to the project folder

```bash
cd AI-Gym-Fitness-Assistant
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
streamlit run app.py
```
